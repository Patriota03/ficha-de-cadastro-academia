# Ficha de Cadastro - Academia Performance

Sistema de cadastro de alunos para a Academia Performance. Aplicacao web em HTML, CSS e JavaScript puro.

## Funcionalidades

- Cadastro de alunos com dados pessoais, matricula e medidas corporais
- Listagem de alunos com busca e estatisticas
- Controle de mensalidades vencidas
- Registro de pagamentos
- Edicao e exclusao de cadastros
- Impressao de fichas
- Layout responsivo (mobile e desktop)
- Tema escuro

## Como Usar

Abra o arquivo `index.html` no navegador ou acesse via GitHub Pages.

## Tecnologias

- HTML5
- CSS3 (Grid, Flexbox, Gradientes)
- JavaScript (localStorage)
